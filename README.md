# prunepack

Prune validation gates for pack inputs before they hit prod.

**Site:** https://theworker02.github.io/prunepack/

## Install / run

```bash
git clone https://github.com/theworker02/prunepack.git
cd prunepack
node src/cli.js
node --test
```
